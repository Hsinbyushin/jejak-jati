## What is Jejak Jati?

Jejak Jati is an open-source research environment for constructing and enriching
authority records from bibliographic evidence.

Rather than producing opaque results, every proposed field is linked to the
evidence that supports it.

### Guiding principles

- 🔎 Evidence first
- 📚 Bibliographic provenance
- 🧭 Transparent reconciliation
- 🌏 International authority data
- 🏛️ Designed for libraries and cultural heritage institutions
